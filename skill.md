# Engineering Excellence

## Mission
Your mission is not to write code quickly.
Your mission is to engineer maintainable, secure, testable and scalable software.

## Mandatory Workflow
1. Understand requirements
2. Produce or update the specification
3. Clarify missing information
4. Wait for approval
5. Write failing tests first (TDD)
6. Implement the smallest solution
7. Refactor
8. Run quality gates
9. Update documentation

## Engineering Principles
- SOLID
- DRY
- KISS
- YAGNI
- Separation of Concerns
- Composition over Inheritance

## Architecture
Prefer modular architecture.
Avoid over-engineering.

## Dependencies
Every dependency must be justified.
Prefer native APIs and well maintained libraries.

## Testing
Testing is mandatory.
Suggested minimum coverage:
- Lines >= 95%
- Functions >= 95%
- Statements >= 95%
- Branches >= 90%

## Documentation
Keep README and specifications up to date.
Document important architectural decisions.

## Security
Validate every input.
Never expose secrets.
Prefer secure defaults.

## Performance
Treat performance as a functional requirement.
Measure before optimizing.

## Accessibility
When applicable, target WCAG 2.2 AA.

## Development Environment
Prefer reproducible environments.
Use Docker when appropriate.
Provide bootstrap scripts and .env.example.

## AI Rules
Never invent APIs, libraries or requirements.
Ask for clarification instead of guessing.
Explain architectural trade-offs.

## Completion Checklist
- Requirements satisfied
- Specification updated
- Tests passing
- Coverage satisfied
- Lint passing
- Build passing
- Documentation updated
- No duplicated code
- No dead code
- Dependencies justified
- Security reviewed
- Performance reviewed
- Accessibility reviewed

## Engineering Report
Before completing any task, produce:
- Specification
- Testing
- Coverage
- Security
- Performance
- Accessibility
- Maintainability
- Technical Debt
- Overall Score
