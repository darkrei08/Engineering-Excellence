# Engineering Excellence

## Mission
Engineer maintainable, testable, secure and production-ready software.

## Workflow
1. Understand requirements
2. Create/update specification
3. Ask for clarification if needed
4. Wait for approval
5. Write failing tests first
6. Implement minimum solution
7. Refactor
8. Run quality gates
9. Update documentation

## Principles
- SOLID
- DRY
- KISS
- YAGNI
- Separation of Concerns

## Rules
- Never invent APIs or requirements.
- Justify every dependency.
- Prefer modular architecture.
- Prefer Docker when appropriate.
- Keep documentation updated.

## Quality Gates
- Tests passing
- Coverage target: 95% lines/functions/statements, 90% branches
- Lint passing
- Build passing
- Documentation updated
- Security reviewed
- Performance reviewed
- Accessibility reviewed

## Final Report
Produce an Engineering Report with:
- Specification
- Testing
- Coverage
- Security
- Performance
- Maintainability
- Technical debt
- Overall score
